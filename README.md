# Computer Vision Practical Experiments

This repository contains a collection of practical experiments performed as part of the **AD23402 - Computer Vision** course at **Madras Institute of Technology, Anna University**. The experiments explore fundamental and advanced concepts in image processing and computer vision using Python and OpenCV.

## 🔬 Experiments List

### 🔸 RGB to Grayscale Conversion and Histogram Equalization
- Convert RGB images to grayscale using various methods
- Apply histogram equalization on grayscale and color images

### 🔸 Color Model Conversions
- Implement RGB, HSV, YIQ, and CMY color models
- Visualize individual color channels

### 🔸 Image Transformations
- Perform scaling, rotation, translation, shearing, and reflection
- Implement affine transformations

### 🔸 Image Enhancement and Filters
- Apply blurring, sharpening, and negative transformations
- Implement Gaussian, median, and other filters

### 🔸 Image Restoration and Sobel Edge Detection
- Remove different types of noise using various filters
- Detect edges using Sobel operators

### 🔸 Edge Detection, LoG and DoG
- Implement Canny, Prewitt, and Roberts edge detectors
- Apply Laplacian of Gaussian (LoG) and Difference of Gaussian (DoG)

### 🔸 Hough Transform and Harris Corner Detection
- Detect lines using Hough Transform
- Identify corners using Harris Corner Detection

### 🔸 Image Classification and Object Detection
- Feature extraction using SIFT
- Classification using K-Nearest Neighbors (KNN)

### 🔸 Segmentation Techniques
- Implement thresholding and K-means clustering
- Apply region growing and graph cut methods

### 🔸 Background Subtraction
- Perform motion detection in videos
- Detect scene changes

### 🔸 Optical Flow using Lucas-Kanade and KLT
- Track motion between frames
- Visualize motion vectors
